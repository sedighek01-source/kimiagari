# ساخت APK اپ کیمیاگری

این پوشه یک پروژهٔ کامل است. اپ داخل پوشهٔ `www` است و همهٔ فونت‌ها داخل خود اپ هستند، پس بعد از نصب بدون اینترنت هم کار می‌کند. اطلاعات روی همان گوشی ذخیره می‌شود.

## روش اول: بدون نصب هیچ برنامه‌ای (پیشنهادی)

گیت‌هاب APK را برایت روی سرور خودش می‌سازد.

1. در github.com یک حساب بساز و یک مخزن (Repository) جدید با نام دلخواه، مثلاً `kimiagari`، بساز.
2. محتوای همین پوشه را داخل مخزن آپلود کن (دکمهٔ Add file و بعد Upload files). پوشهٔ `.github` را هم حتماً آپلود کن. اگر در فهرست فایل‌ها پنهان بود، از روش دوم استفاده کن یا پوشه را کامل بکش و رها کن.
3. به تب Actions برو. گردش‌کار «Build APK» خودش شروع می‌شود (حدود ۵ تا ۸ دقیقه). اگر شروع نشد، آن را انتخاب کن و Run workflow را بزن.
4. وقتی سبز شد، واردش شو. پایین صفحه در بخش Artifacts فایل `kimiagari-apk` را دانلود کن.
5. فایل zip را باز کن. داخلش `app-debug.apk` است. آن را به گوشی بفرست و نصب کن. اندروید ممکن است بخواهد «نصب از منابع ناشناس» را برای مرورگر یا مدیر فایل روشن کنی.

## روش دوم: با Android Studio روی کامپیوتر

1. Node.js و Android Studio را نصب کن.
2. در پوشهٔ پروژه این دستورها را اجرا کن:

```
npm install
npx cap add android
npx capacitor-assets generate --android
npx cap sync android
npx cap open android
```

3. در Android Studio از منوی Build گزینهٔ Build APK(s) را بزن. فایل خروجی در `android/app/build/outputs/apk/debug` است.

## نکته‌ها

- این APK با کلید آزمایشی (debug) ساخته می‌شود. برای نصب مستقیم کافی است. برای گذاشتن در کافه‌بازار، مایکت یا گوگل‌پلی باید نسخهٔ release با کلید امضای خودت بسازی. اگر خواستی، همین را از من بخواه.
- اگر بعداً چیزی را در اپ عوض کردی، فقط `www/index.html` را عوض کن و دوباره یکی از دو روش بالا را اجرا کن. نصب نسخهٔ جدید روی قبلی، اطلاعات را نگه می‌دارد.
- شناسهٔ اپ `com.kimiagari.app` است و در `capacitor.config.json` قابل تغییر است.
